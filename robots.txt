# robots.txt for tmnmv.com
#
# /tony.html is an EMPLOYER-ONLY page. Tony hands out the direct link in
# job applications. It must never show up in search results or in an AI
# answer, but it must stay fetchable so an employer can open it.
#
# Googlebot and Bingbot are deliberately NOT blocked from /tony.html.
# They must be able to fetch the page to read the noindex meta tag in its
# head. Blocking them would leave a bare URL in the index instead of
# removing it. The noindex tag lives in tony.html: <meta name="robots"
# content="noindex, nofollow">.
#
# Cloudflare prepends its own managed robots.txt to this file when the
# origin returns 200 for robots.txt (Cloudflare docs, updated 2026-11-02).
# The Cloudflare-managed AI-crawler denylist is replicated at the bottom of
# this file so the policy is identical whether Cloudflare prepends or
# replaces. Keep the two copies in sync if you change either.

User-agent: *
Content-Signal: search=yes,ai-train=no,use=reference
Allow: /

# --- AI index and search agents: do not retrieve the employer-only page ---
#
# Only the indexing agents are blocked. The user-triggered fetchers
# (ChatGPT-User, Perplexity-User, Claude-User) are deliberately left
# allowed: they fire only when a human pastes the link, which is exactly
# what a recruiter does with it.
User-agent: OAI-SearchBot

User-agent: PerplexityBot

User-agent: Claude-SearchBot
